# 招新报名数据清洗与统计

> 把问卷导出的 CSV，变成一份看得懂、查得到、能继续使用的数据。

一个轻量的 Python 命令行工具：先汇总报名表，再检查学号、邮箱和重复报名，最后输出问题清单、志愿统计和干净数据。程序只使用 Python 标准库，不会覆盖原始 CSV。

## 功能一览

| 阶段 | 做什么 | 结果 |
| --- | --- | --- |
| 📊 概览 | 统计总行数、各列空值和完全重复行 | 终端摘要 |
| 🔎 校验 | 检查学号、邮箱和重复报名，并说明每行的问题 | `问题清单.csv` |
| 📈 统计 | 按第一志愿统计人数，汇总志愿填写情况 | `第一志愿统计.csv` 和终端摘要 |
| 🧹 导出 | 排除未通过校验的记录，另存干净数据 | `干净数据.csv` |

## 快速开始

### 1. 准备 Python

需要 **Python 3.10 或更新版本**。本项目只使用标准库，不需要安装第三方包。

```bash
python3 --version
```

### 2. 准备报名 CSV

将问卷导出的文件保存为 UTF-8 CSV，例如 `报名表.csv`。首行应包含项目要求的六个字段，字段顺序可以不同。

```csv
姓名,学号,邮箱,志愿1,志愿2,推荐人
小林,20260001,20260001@smbu.edu.cn,项目开发部,创新创业部,小周
```

### 3. 运行

在仓库目录中执行：

```bash
python3 signup_cleaner.py 报名表.csv
```

默认结果保存在当前目录的 `output/` 文件夹。也可以指定目录：

```bash
python3 signup_cleaner.py 报名表.csv --output-dir 处理结果
```

## 输入格式

CSV 必须包含以下列；可以有额外列，但工具只读取并处理这些必需字段：

| 字段 | 用途 |
| --- | --- |
| `姓名` | 报名者姓名 |
| `学号` | 学号校验与重复报名识别 |
| `邮箱` | 与学号对应的学校邮箱校验 |
| `志愿1` | 第一志愿分组统计 |
| `志愿2` | 志愿填写情况统计 |
| `推荐人` | 保留在问题清单和干净数据中 |

支持 UTF-8 和带 BOM 的 UTF-8 文件。列名需与上表完全一致。

## 输出文件

程序会创建输出目录，并写入三份 CSV：

| 文件 | 内容 |
| --- | --- |
| `问题清单.csv` | 问题记录、原 CSV 行号和问题原因；同一行的多种原因会一起列出 |
| `第一志愿统计.csv` | 通过校验的记录按第一志愿汇总的人数 |
| `干净数据.csv` | 通过学号、邮箱和重复学号检查的记录 |

终端还会显示报名总数、每列空值数、完全重复行数、问题行数、干净数据行数、志愿填写情况和第一志愿统计。

> 原始报名文件只读，不会被修改。生成的 CSV 使用 UTF-8 编码并带 BOM，方便在常见表格软件中打开。

## 校验规则与边界假设

- **学号**：必须由一个或多个 ASCII 数字组成，位数不限；保留前导零。空学号或含空格的学号不合规。
- **邮箱**：必须严格等于该行学号加上 `@smbu.edu.cn`。不自动去除空格，也不调整大小写。
- **重复报名**：同一非空学号出现多次时，该学号的每一行都会列入问题清单，并从干净数据中排除。
- **完全重复行**：按六个必需字段判断；报告重复记录的额外出现次数。例如相同行出现两次，计为 1 行重复。
- **空值**：首尾空白去除后为空即视为空值。姓名、志愿或推荐人为空会计入概览，但不会单独导致记录被剔除。
- **志愿统计**：仅统计干净数据。第一志愿为空的记录归入“（未填写）”；“只填写一个”表示两个志愿中恰有一项非空，两项都空不计入。
- **问题清单行号**：按 CSV 文件中的实际行号记录，表头为第 1 行，因此第一条数据从第 2 行开始。

## 处理流程

```text
报名 CSV → 概览 → 学号 / 邮箱 / 重复检查 → 问题清单
                                      └→ 干净数据 → 志愿统计
```

只有通过上述三项校验的记录会进入干净数据及志愿统计。工具不会根据未列出的规则擅自删除记录。

## 常见问题

**提示缺少必需字段怎么办？**

检查 CSV 首行的列名是否与“输入格式”中的六个字段完全一致，包括数字和空格。

**为什么邮箱看起来正确，仍被判定为不匹配？**

校验采用严格相等比较。请检查邮箱前后是否有空格、学号是否一致，以及域名大小写是否完全相同。

**可以直接用 Excel 打开输出文件吗？**

可以。输出文件为带 UTF-8 BOM 的 CSV；如果中文仍显示异常，请在表格软件中选择 UTF-8 编码导入。
