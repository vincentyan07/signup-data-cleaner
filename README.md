# 招新报名数据清洗与统计

一个仅使用 Python 标准库的 CSV 命令行工具。它会读取问卷导出的报名表，在终端打印数据概览和统计，并将问题清单、第一志愿汇总及干净数据写入新文件。

## 环境要求

- Python 3.10 或更新版本
- CSV 文件使用 UTF-8 编码（支持 UTF-8 BOM）

## 输入格式

CSV 表头必须包含以下六列（可有其他列；程序只处理这六列）：

`姓名`、`学号`、`邮箱`、`志愿1`、`志愿2`、`推荐人`

## 运行

```bash
python3 signup_cleaner.py 报名表.csv
```

默认在当前目录创建 `output/` 并写入：

- `问题清单.csv`：每个问题行保留原字段、输入文件行号和问题原因。学号不合规、邮箱不匹配和重复学号会分别说明；一行可有多个原因。
- `第一志愿统计.csv`：按第一志愿汇总干净数据中的人数。
- `干净数据.csv`：移除所有被判定为问题的报名行后生成，原 CSV 不会被修改。

可用 `-o` 指定输出目录：

```bash
python3 signup_cleaner.py 报名表.csv --output-dir 处理结果
```

## 校验规则与边界假设

- 学号只检查是否由一个或多个 ASCII 数字字符组成；位数不限，前导零保留。空学号和包含空格的学号均不合规。
- 邮箱必须逐字等于该行学号加上 `@smbu.edu.cn`；不自动修剪空格、不转换大小写。
- 同一学号在输入文件出现多次时，该学号的每一行都进入问题清单，并从干净数据中排除。空学号不作为重复报名依据。
- 问题清单的 CSV 行号从 2 开始（首行为表头）。完全重复行数指重复记录的额外出现次数，例如同一行出现两次计 1。
- 空值按去除首尾空白后为空计算。志愿人数统计基于干净数据；第一志愿为空的记录在汇总中列为“（未填写）”。“两个志愿都填写”要求两列都非空；“只填写一个”指两列中恰有一列非空。两列都空不计入这两项。
- “干净”仅表示通过本工具明示的学号、邮箱和重复学号检查；姓名、志愿或推荐人为空不会单独导致该行被剔除。

## 概览

终端会显示总行数、每列空值数、完全重复行数、问题行数、干净数据行数、两项志愿填写统计和第一志愿人数。
